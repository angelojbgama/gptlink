# GPTLink v0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Entregar um Gateway, Agent Linux, protocolo próprio e adapter MCP seguros e testáveis, com adapters Windows preparados para validação real posterior.

**Architecture:** Serviços de domínio independem de transports. FastAPI hospeda o WebSocket do protocolo GPTLink e monta o servidor MCP oficial; o Agent outbound aplica uma segunda camada de política local e executa operações somente em roots permitidos.

**Tech Stack:** Python 3.12, FastAPI, asyncio/websockets, Pydantic v2, SQLAlchemy 2 async, SQLite/aiosqlite, MCP Python SDK v2, Typer, pytest, ruff, mypy, Docker.

**Spec:** `docs/architecture.md`

## Global Constraints

- Produto/package/executáveis: `GPTLink`, `gptlink`, `gptlink` e `gptlink-agent`.
- Protocolo GPTLink interno inicia em versão inteira `1`.
- MCP mira `2026-07-28` via SDK oficial v2 e Streamable HTTP stateless.
- Agent inicia toda conexão; produção exige HTTPS/WSS.
- Device tokens têm no mínimo 256 bits e só hash é persistido.
- Roots `/` e `C:\\` são negados; toda autorização usa caminho resolvido.
- Nenhum delete, kill via MCP, shutdown, reset/clean Git ou bypass de policy.
- SQL fica em persistence/repositories; MCP não contém regra de negócio.

## Self-review

Every required subsystem maps to one task; dependencies flow from common types
and protocol through persistence/transports to adapters. Destructive operations
remain absent. Windows real execution and Docker cannot be claimed on this host
unless their runtimes become available. The plan contains no hidden MCP session
state and no transport is allowed to bypass the shared Gateway services or Agent
policy.
